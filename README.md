# CINDERVALE

A co-op browser RPG. GBA-style pixel art, all generated in code — no downloaded assets. One HTML file.

Up to 10 players share one room. Light three embers to wake the Hollow King, then fight him together.

## Controls
- **Desktop:** WASD/arrows move · J/Space or left-click to strike · K/Shift dash
- **Mobile:** touch D-pad and STRIKE/DASH appear automatically
- **Gamepad:** left stick/D-pad move · A/X strike · B/RB dash (hides touch controls)

## Play together
HOST GAME → share the 4-letter code or link → Enter to start. Multiplayer uses WebRTC via PeerJS (needs HTTPS, which GitHub Pages provides).
